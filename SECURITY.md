# Security reports

For a vulnerability that could expose data or execute unintended code, use GitHub private vulnerability reporting for this repository. Avoid posting credentials, secret fixtures, or exploit details in a public issue.

The initial supported release line is 0.1.x. PolicyDelta operates on synthetic fixtures in its own local development servers; it has no production endpoint or credential option. Supply your own trusted policy files and trusted OpenBao executable. Do not use production secret values in suites.

Please include the affected version, minimal synthetic reproduction, observed impact, and relevant operating system. Ordinary defects and improvements can be reported as public issues without private data.
